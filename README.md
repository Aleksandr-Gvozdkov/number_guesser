# Number Guessing Game (Числовая угадайка) 🎯

Консольная мини-игра на Python, в которой компьютер загадывает случайное число от 1 до 100, а игрок должен его угадать с помощью подсказок.

## Как запустить

1. Убедитесь, что у вас установлен Python 3.
2. Скачайте файл `number_guesser.py` и перейдите в папку с ним в терминале.
3. Запустите скрипт:
   ```bash
   python3 guess_number.py
   ```
